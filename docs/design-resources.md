## 用途別クイックガイド

- **ページ全体を作る** → Scrolltide / VibePrompt / DESIGNmd でブリーフを作り、Minimal Gallery・Refero Styles で方向性を決める
- **特定パーツを作る** → Navbar / Footer / CTA / 404s / Component Gallery で事例を確認
- **実装** → shadcn/ui をベースに、Aceternity UI / Magic UI / Motion Primitives で動きを足す（21st.dev は MCP 連携可）
- **仕上げ** → Kinetics / MicroKit / Liquid Glass / Text Effects などで演出、Kitbitz・3Dicons でビジュアル素材
- **モバイル** → AppShot Gallery
- **地図** → mapcn
