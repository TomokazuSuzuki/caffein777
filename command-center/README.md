# プロジェクト司令塔

Claude で動かしているプロジェクトを忘れずに進めるための 1 ファイルの Web アプリです。

- **いま手を付けるべきこと**：入力待ちの Claude セッション、期限切れ・期限間近、放置しているプロジェクト、今日の予定をまとめて表示
- **プロジェクト**：状態・優先度・期限と「次の一手」（再開するための一文）を管理。「進めた」で今日の進捗を記録
- **予定**：7 日間のアジェンダ。予定や締切を追加・完了できる
- **Claude セッション**：Claude Code Remote コネクタでセッション一覧を取得し、プロジェクトに紐付け。使用額の合計からクレジットの残りを概算

公開版（データはクラウドに保存）: https://claude.ai/artifact/TZDAa4pNjhFHDUb7vaT48f

`index.html` をブラウザで直接開いた場合は、データはそのブラウザの localStorage にだけ保存され、セッション一覧は表示されません。
